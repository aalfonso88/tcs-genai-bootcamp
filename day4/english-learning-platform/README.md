# English Learning Platform (prototype)

This repository contains a small prototype for an English learning platform (students & teachers). Run the backend and frontend locally as described in `specs/001-init-english-platform/quickstart.md`.

Backend: `backend/` (FastAPI + SQLModel, SQLite `backend/dev.db`)
Frontend: `frontend/` (React + Vite)

This is an early prototype — no authentication included. Use the demo role selector in the footer to switch between `Estudiante` and `Profesor`.
