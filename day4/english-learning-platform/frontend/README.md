# Frontend — React + Vite

Quick start:

1. From repository root:

```bash
cd frontend
npm install
./node_modules/.bin/vite
```

The Vite dev server will print the local URL (usually `http://localhost:5173/`; if that port is busy Vite will choose an adjacent port such as `5174`).

Use the footer role selector to switch between Estudiante and Profesor views.
